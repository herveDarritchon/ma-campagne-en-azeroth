# Modules Foundry VTT les plus utiles pour D&D5e

## 1. Dice So Nice! — ★★★★★ Indispensable

**55,16 % des utilisateurs Foundry.**

Affiche les jets sous forme de vrais dés 3D animés avec physique, sons et personnalisation. Compatible v14.

**Pourquoi l'utiliser :** parce qu'un jet important doit rester un moment de JdR. L'automatisation ne doit pas transformer D&D en suite de valeurs apparaissant dans le chat.

**Comment l'utiliser :**

- activer les dés 3D pour tous ;
    
- laisser chaque joueur personnaliser ses dés ;
    
- conserver les jets importants visibles ;
    
- éventuellement ajouter des effets particuliers sur critiques.
    

**Pour Champions of Azeroth :** oui, sans hésiter.

---

## 2. Dice Tray — ★★★★★ Indispensable

**42,05 %.**

Ajoute directement sous le chat des boutons d4, d6, d8, d10, d12, d20 ainsi qu'un calculateur de dés. Compatible v14.

**Pourquoi :** accélère tous les jets improvisés du MJ et des joueurs.

**Comment :** essentiellement aucun réglage. Installe-le et utilise-le avec Dice So Nice.

**CoA :** oui.

# INTERFACE DE JEU

## 3. Token Action HUD Core + Token Action HUD D&D5e — ★★★★★

**24,65 % pour le Core.**

Affiche les actions du personnage directement sur l'écran lorsque son token est sélectionné : attaques, sorts, compétences, objets, actions, etc. Le module D&D5e est actuellement vérifié pour Foundry v14.

**Pourquoi :** c'est probablement l'un des modules qui rapproche le plus Foundry d'un **RPG informatique**.

Au lieu de :

`Token → ouvrir fiche → onglet attaque → trouver capacité → cliquer`

on obtient :

`Token → compétence → clic`

**Pour CoA :** **très fortement recommandé**. Les joueurs retrouveront davantage la sensation des barres d'actions de WoW.

**Réglage conseillé :**

- attaques ;
    
- actions ;
    
- bonus actions ;
    
- sorts ;
    
- objets consommables ;
    
- compétences importantes.
    

Évite cependant d'afficher absolument tout : un HUD surchargé produit l'effet inverse.

---

## 4. Tidy 5e Sheets — ★★★★★

Ce module n'apparaît pas dans le Top 30 global parce qu'il est spécifiquement D&D5e, mais c'est l'un des modules D&D5e que je retiendrais en priorité.

Il remplace les fiches par une interface plus ergonomique et personnalisable. La nouvelle interface **Quadrone** est vérifiée Foundry v14 et D&D5e 5.3.x.

**Pourquoi :**

- meilleure hiérarchie des informations ;
    
- meilleure navigation ;
    
- fiche plus agréable pour les joueurs ;
    
- bonne base pour tes classes Champions of Azeroth.
    

**CoA :** oui, particulièrement intéressant si nous voulons ensuite adapter visuellement les fiches à Warcraft.

# COMBAT ET AUTOMATISATION

## 5. Midi-QOL — ★★★★★ mais à maîtriser

**20,82 % des utilisateurs Foundry.**

C'est le gros moteur d'automatisation D&D5e : attaques, cibles, jets de sauvegarde, dégâts, résistances, effets, workflows de combat, etc. La branche 14 est maintenant disponible pour Foundry v14.

### Sans Midi

> Je cible le scorpide → attaque → résultat → le MJ vérifie la CA → dégâts → joueur applique les dégâts.

### Avec Midi

> Je cible le scorpide → attaque → Foundry vérifie le toucher → dégâts → résistances → PV.

**Pourquoi l'utiliser :** énorme accélération des combats.

**Mais je déconseille l'automatisation totale.**

Pour ta campagne, je viserais une **automatisation moyenne** :

- ciblage obligatoire ;
    
- calcul automatique hit/miss ;
    
- sauvegardes facilitées ;
    
- application automatique des dégâts ;
    
- résistances/vulnérabilités ;
    
- conditions automatisées lorsque c'est fiable ;
    
- laisser les joueurs lancer réellement leurs dés.
    

Cela conserve le JdR tout en supprimant la comptabilité.

**CoA : excellent**, mais toutes les capacités Warcraft devront être testées. Midi ne peut pas deviner comment fonctionne une capacité homebrew.

## 6. Dynamic Active Effects — DAE — ★★★★★

**25,57 %.**

DAE étend les Active Effects pour permettre aux objets, sorts et capacités de modifier dynamiquement les caractéristiques d'un Actor. Version v14 disponible.

Exemple :

**Bloodlust**

→ vitesse modifiée  
→ bonus approprié  
→ effet actif  
→ suppression à expiration.

Ou :

**Forme d'ours**

→ changement de caractéristiques  
→ résistances  
→ modifications temporaires.

**Pourquoi :** particulièrement important pour Champions of Azeroth avec tous ses buffs, debuffs, postures, formes, capacités et effets temporaires.

**CoA : presque indispensable si on automatise.**

---

## 7. Automated Conditions 5e — ★★★★☆

Module D&D5e moderne, actuellement développé pour v14. Il peut faire intervenir automatiquement conditions, bonus, désavantages, auras et autres effets dans les jets.

Exemple :

`Poisoned`

→ Foundry sait que certaines attaques/ability checks doivent être faites avec désavantage.

**Pourquoi :** évite au joueur et au MJ de devoir se rappeler en permanence de tous les modificateurs.

**CoA : très intéressant**, notamment pour les combats de boss riches en effets.

---

## 8. Monk's Combat Details — ★★★★☆

Améliore le déroulement du combat : annonce du tour, avertissement « tu joues après », amélioration du combat tracker, informations de combat, etc. Compatible v14.

**Pourquoi :** avec cinq joueurs en ligne, les temps morts entre deux tours sont l'un des principaux tueurs de rythme.

Le petit :

> **YOUR TURN**

a beaucoup plus d'effet qu'on pourrait le croire.

**CoA : recommandé.**

---

## 9. Carousel Combat Tracker — ★★★★☆ / ★★★★★ pour ton projet

**20,42 %.**

Successeur moderne de l'ancien Combat Carousel. Affiche les participants à un combat sous la forme d'un bandeau/carrousel type CRPG. Compatible v14.

# Ce que je N'installerais plus automatiquement en v14

C'est ici que les anciennes listes de « modules indispensables Foundry » deviennent trompeuses.

### Times Up

**Non.**

L'auteur indique explicitement qu'il n'y aura **pas de version Foundry v14** : le Core couvre désormais l'essentiel de sa fonction et les fonctionnalités restantes ont été déplacées dans DAE.

### Levels

Je ne l'installerais plus par principe.

Foundry v14 possède maintenant nativement les **Scene Levels**, les changements de niveaux, les surfaces et une architecture de scènes multi-étages.

À installer uniquement si une fonction spécifique du module Levels nous manque réellement.

### PopOut!

Même logique.

V14 sait désormais détacher nativement les fenêtres ApplicationV2.

### Trop de modules d'automatisation

C'est un piège.

**Midi-QOL + DAE + Automated Conditions + 15 modules de premades + macros diverses** peut aboutir à une usine où personne ne sait plus quel module vient de modifier un jet.

Pour Champions of Azeroth, dont nous allons créer nous-mêmes une partie des Items et capacités, je préfère une pile **compréhensible et maîtrisée**.

# Priorité d'installation

Je ne mettrais surtout pas les 19 d'un coup.

**Étape 1 — Interface**  
Dice So Nice → Dice Tray → Tidy → Token Action HUD → Tokenizer.

**Étape 2 — Combat**  
Midi-QOL → DAE → Automated Conditions → Monk's Combat Details.

**Étape 3 — « WoW effect »**  
Sequencer → JB2A → Automated Animations → D&D5e Animations → FXMaster.

**Étape 4 — Monde**  
Item Piles → MATT → Monk's TokenBar → Quick Insert → Carousel.

À chaque étape : **tester avant d'ajouter la suivante**.

C'est particulièrement important avec Midi-QOL/DAE : le but n'est pas d'avoir le Foundry le plus automatisé possible, mais d'avoir **le Foundry dont on comprend exactement le comportement**.
