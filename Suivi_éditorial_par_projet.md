# Suivi éditorial par projet — Au Nom de la Horde

> Index de tâches pour piloter le vault par chantiers. Les cases servent à décider quoi faire ensuite sans devoir relire tout le corpus.

## Légende

- **Priorité haute** : débloque la jouabilité, la navigation ou la production.
- **Priorité moyenne** : améliore la qualité, la cohérence ou la réutilisabilité.
- **Priorité basse** : finition, confort, enrichissement.

---

# 1. Organisation générale du vault

## Statut

Base créée via `jdr-scaffold` : index, règles de design (GDR), templates, bases Obsidian et orchestrateurs LLM en place.

## Tâches

- [x] Initialiser le vault avec `jdr-scaffold`.
- [x] Vérifier la configuration `_CLAUDE.md`, `AGENTS.md` et `GEMINI.md`.
- [ ] Personnaliser la description de la campagne dans `[[Index_du_Vault]]`.
- [ ] Créer les premiers PNJ clés dans `PNJs/`.
- [ ] Créer les premiers Lieux & POI majeurs dans `Localisations/`.
- [ ] Définir la première aventure / arc narratif dans `Campagnes/`.
