# Open Situation Design

Utilise ce skill pour générer des situations jouables à partir de fronts, factions, lieux ou horloges.

## Objectif

Créer une situation activable en jeu, sans imposer une scène obligatoire ni une solution unique.

## Une situation ouverte doit contenir

- Un déclencheur.
- Ce qui se passe concrètement.
- Pourquoi cela arrive maintenant.
- Les factions impliquées.
- Ce que les PJ peuvent vouloir.
- Des complications possibles.
- Plusieurs issues possibles.
- Des conséquences sur les horloges ou les relations.

## Règles

- Ne suppose pas que les PJ feront le bon choix.
- Ne verrouille pas une information vitale derrière un seul jet.
- Ne force pas l'apparition d'une faction sans raison.
- Ne prépare pas une scène obligatoire.
- Prévois action, inaction, échec, compromis.
- Toute invention doit être étiquetée.

## Format recommandé

```markdown
# Situation — [Titre]

## Déclencheur

## Ce qui se passe

## Pourquoi maintenant

## Factions impliquées

## Ce que les PJ peuvent vouloir

## Complications possibles

## Issues possibles

## Conséquences sur les horloges

## Notes de statut
```

## Test rapide

Si la situation n'a qu'une seule entrée ou une seule issue, elle est trop linéaire.
