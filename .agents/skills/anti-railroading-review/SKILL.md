# Anti-Railroading Review

Utilise ce skill pour relire un front, une situation, un lieu ou un contenu narratif.

## Objectif

Détecter tout ce qui force les PJ à suivre une trajectoire prédéfinie.

## Signaux d'alerte

- Une scène doit absolument arriver.
- Les PJ doivent obligatoirement parler à un PNJ précis.
- Une révélation vitale dépend d'un seul jet.
- Une seule solution est prévue.
- Le climax est déjà fixé.
- Une faction intervient sans raison pour remettre l'intrigue sur les rails.
- Les conséquences des choix des PJ sont neutralisées.
- Les échecs ne produisent que du blocage.
- Les joueurs ont l'impression de choisir, mais toutes les routes mènent au même résultat.

## Méthode

1. Identifie les passages imposés.
2. Repère les informations verrouillées.
3. Vérifie les alternatives d'entrée et de sortie.
4. Remplace les scènes obligatoires par des pressions.
5. Remplace les solutions uniques par des conséquences multiples.

## Format recommandé

```markdown
## Risques de railroading

### Scènes ou passages obligatoires

### Révélations verrouillées

### Solutions uniques

### Conséquences neutralisées

### Corrections recommandées
```

## Règle de rigueur

Un contenu n'est pas ouvert parce qu'il propose trois chemins vers la même conclusion.
