# Table Usability Review

Utilise ce skill pour vérifier si un contenu peut réellement servir en partie.

## Objectif

Couper ce qui est joli mais inutile, clarifier ce qui est flou, rendre le contenu actionnable.

## Points à vérifier

- Le MJ comprend rapidement la fonction du contenu.
- Les informations importantes sont faciles à retrouver.
- Les paragraphes ne sont pas inutilement longs.
- Les enjeux sont concrets.
- Les PNJ, factions ou lieux ont une utilité en jeu.
- Les conséquences sont jouables.
- Les détails servent une décision, une tension ou une situation.
- Le contenu peut être utilisé sans relire trois pages.

## Méthode

1. Identifie la fonction de jeu.
2. Supprime ou signale le décoratif inutile.
3. Vérifie la lisibilité des titres.
4. Cherche les éléments directement jouables.
5. Propose une version plus courte si nécessaire.

## Format recommandé

```markdown
## Utilisabilité en table

### Fonction de jeu

### Éléments immédiatement jouables

### Passages trop longs ou flous

### Informations difficiles à retrouver

### Corrections recommandées

### Version resserrée
```

## Test rapide

Si le MJ ne peut pas utiliser le contenu pendant une partie, le contenu doit être resserré.
